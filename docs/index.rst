AtomDefectKit documentation
===========================

AtomDefectKit is a Python package for atomistic defect workflows focused on BCC
metals, defect energetics, screw dislocations, and traction-separation
calculations.

The package includes:

* calculator loading through a model registry
* bulk and point-defect property workflows
* screw-dislocation and NEB workflows
* stacking-fault and traction-separation tools
